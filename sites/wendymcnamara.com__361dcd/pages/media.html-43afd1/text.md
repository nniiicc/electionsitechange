To download a Hi-Res photo:
Select the photo that you want by clicking on the thumbnail image.
The photo will expand to a larger image.
From here you can either:
Right-click and select ‘Save Picture As’ to rename the file and select its’ location
-or-
Go to File and select ‘Save As’ to rename the file and select its’ location
