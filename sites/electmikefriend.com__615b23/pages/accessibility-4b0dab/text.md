We are continually improving the user experience for everyone and applying the relevant accessibility standards to guarantee we provide equal access to all of our users, regardless of ability.
We aim to adhere strictly to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.
Accessibility Features Implemented We have incorporated a comprehensive set of features designed to improve the accessibility of our website: Semantically Structured Content: Use of clear and consistent heading hierarchies (H1-H6) and landmark elements (main, nav, footer) to aid screen readers and keyboard navigation.
Text Alternatives: Descriptive alternative text ("alt text") is provided for all meaningful images to assist visually impaired users.
Keyboard Navigation: All interactive elements, including menus, links, and forms, can be accessed and operated using a keyboard alone.
A "Skip to Main Content" link is provided at the top of the document.
Visual Contrast & Color: We ensure a strong contrast ratio between text and backgrounds to meet or exceed WCAG AA standards (4.5:1 for normal text).
Information is never conveyed by color alone.
Focus Indicators: Clear, highly visible focus states are provided for all interactive components to help users track their location on the page.
Accessible Forms: All forms include proper labels, ARIA validation states, and courteous error messages announced via aria-live regions.
Compatibility and Testing Our website is designed to be compatible with standard assistive technologies, including popular screen readers (such as JAWS, NVDA, and VoiceOver) and standard web browsers across operating systems.
We regularly test our platform using automated accessibility checking tools (like axe and Lighthouse) and perform manual audits focusing on keyboard-only navigation and screen reader behavior to ensure continuous compliance.
Need Assistance?
If you encounter any barriers or have difficulty accessing any part of this website, please let us know immediately so we can address the issue.
