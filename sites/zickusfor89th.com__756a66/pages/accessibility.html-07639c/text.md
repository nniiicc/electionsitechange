Accessibility
Accessibility statement
Zickus for 89th is committed to providing a website that is usable by as many people as possible, including people who use assistive technology.
Accessibility measures
- Semantic HTML landmarks and a logical heading structure
- A keyboard-accessible navigation menu and skip link
- Visible keyboard focus indicators
- Text and interface colors designed for WCAG AA contrast
- Alternative text for meaningful images
- Responsive layouts that support text enlargement and narrow screens
- Reduced-motion support for visitors who request it
- Descriptive link text and clear external-link behavior
Our goal
The site is designed toward conformance with WCAG 2.2 Level AA.
Accessibility is an ongoing process, and automated checks cannot identify every possible barrier.
Need help accessing information?
If you encounter an accessibility barrier, please contact the campaign through Facebook (opens in a new tab) or Instagram (opens in a new tab), or write to 11833 78th Ave, Allendale, MI 49401.
Review status
On September 9, 2026, the nine public pages were reviewed using automated accessibility checks and browser tests for keyboard navigation, narrow-screen layouts, text enlargement and text spacing.
Changes addressed navigation, focus, photo captions, map descriptions and page structure.
Automated and browser checks do not verify every WCAG requirement.
Independent testing with screen-reader users remains to be completed; this statement is not a claim of full conformance.
