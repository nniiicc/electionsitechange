I am continually working to improve the user experience for everyone and to apply relevant accessibility standards.
This website is built using Wix, which provides tools designed to help meet accessibility guidelines, including compatibility with screen readers, keyboard navigation, and adjustable text sizing.
Efforts to Support Accessibility I aim to follow the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA whenever reasonably possible.
Current efforts include: Providing clear navigation and readable text Using accessible color contrast where possible Adding alternative text to images when available Ensuring the site can be navigated by keyboard Structuring content clearly for assistive technologies Accessibility is an ongoing process, and improvements will continue to be made.
