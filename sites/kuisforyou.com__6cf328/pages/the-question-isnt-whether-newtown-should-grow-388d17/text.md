The question isn’t whether Newtown should grow.
It’s whether that growth is going to be planned, fair, and supported — or rushed onto towns without the resources to handle it.
Michelle knows Newtown families deserve a better answer than just deal with it.
- Count what’s already here instead of ignoring it.
- Reward smart development in the right places.
- Make sure the state puts real support behind the changes it expects communities to absorb.
