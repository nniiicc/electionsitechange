Frank Roberts is a Clean Elections Candidate Clean Elections keeps the campaign accountable to voters.
Many Arizonans do not realize it, but there is a way to run for office without taking a single penny from corporations, unions, or lobbyists.
It is called the Citizens Clean Elections program, and it allows candidates like Frank Roberts to run a truly grassroots, people-powered campaign.
People-powered 1998 Created by Arizona voters to give candidates a clean path to run for office.
How it works A cleaner campaign, by design.
01 Reject special-interest money Clean Elections candidates agree to strict guidelines, including rejecting corporate, union, lobbyist, and PAC money.
02 Qualify through voters Candidates prove grassroots support by collecting required qualifying contributions from eligible voters.
03 Run with accountability The system emphasizes public funding, campaign finance reporting, and more time spent talking directly with voters.
