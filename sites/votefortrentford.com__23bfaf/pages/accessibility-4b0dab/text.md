Trent Ford for Alabama House District 7 is committed to ensuring digital accessibility for people with disabilities.
We are continually improving the user experience for everyone and applying the relevant accessibility standards to ensure we provide equal access to all users.
We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.
These guidelines explain how to make web content more accessible for people with disabilities and more user-friendly for everyone.
Our website includes the following accessibility features:
- Semantic HTML: Proper use of HTML elements to convey meaning and structure
- Alt Text: Descriptive alternative text for images
- Keyboard Navigation: Full site navigation using keyboard only
- Color Contrast: Sufficient color contrast ratios for text readability
- Responsive Design: Mobile-friendly layout that adapts to different screen sizes
- Clear Focus Indicators: Visible focus states for interactive elements
- Readable Fonts: Clear, legible typography throughout the site
- ARIA Labels: Screen reader support through appropriate ARIA attributes
Our website includes embedded content from third-party platforms including YouTube, Facebook, Instagram, and Substack.
While we strive to ensure all content is accessible, we cannot control the accessibility of third-party services.
We encourage you to visit these platforms' accessibility statements for more information:
This website is designed to be compatible with the following assistive technologies:
- Screen readers (JAWS, NVDA, VoiceOver, TalkBack)
- Screen magnification software
- Speech recognition software
- Keyboard-only navigation
- Browser text resizing and zoom features
Despite our best efforts to ensure accessibility, some limitations may exist:
- Third-party embedded content (videos, social media widgets) may have accessibility limitations beyond our control
- Some older browsers may not fully support all accessibility features
- PDF documents, when available, may require additional accessibility accommodations
We are actively working to address these limitations and improve accessibility across all aspects of our site.
