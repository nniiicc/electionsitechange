Accessibility Statement
Effective Date: 02/26/2026
Friends of Rich Szabo is committed to ensuring digital accessibility for all users, including individuals with disabilities.
We are continually working to improve the user experience and apply relevant accessibility standards to enhance website usability.
Accessibility Efforts
We strive to:
- Follow recognized web accessibility guidelines (WCAG standards where feasible)
- Use clear, readable fonts and high-contrast color combinations
- Provide alternative text for images
- Structure content for screen reader compatibility
- Maintain keyboard navigability
Ongoing Improvements
Accessibility is an ongoing effort.
As technology and standards evolve, we will continue reviewing and improving website accessibility.
Need Assistance?
If you experience difficulty accessing any part of this website, please contact us so we can provide the information in an alternative format.
