Lauren Jewett for Congress is committed to ensuring digital accessibility for all users
As a special education teacher with 17 years of experience, Lauren Jewett understands the importance of accessibility firsthand.
We are committed to ensuring that our website is accessible to all users, including those with disabilities.
We believe that everyone deserves equal access to information about our campaign and how to get involved in the democratic process.
Our website aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.
These guidelines explain how to make web content more accessible for people with disabilities.
We go beyond basic compliance to provide an exceptional experience for all users, including:
- Enhanced keyboard navigation with visible focus indicators
- High contrast color schemes for better readability
- Descriptive alt text for all images
- Proper heading structure for screen readers
- ARIA labels and landmarks for assistive technologies
- Reduced motion options for users with vestibular disorders
- Minimum 44px touch targets for mobile accessibility
- Skip Navigation: Skip to main content links for screen reader users
- Keyboard Navigation: All interactive elements are accessible via keyboard
- Screen Reader Support: Semantic HTML and ARIA labels throughout
- Color Contrast: All text meets WCAG AA contrast requirements
- Responsive Design: Works on all devices and screen sizes
- Alternative Formats: Content available in multiple formats upon request
We regularly test our website with:
- Screen readers (NVDA, JAWS, VoiceOver)
- Keyboard-only navigation
- Color contrast analyzers
- Mobile accessibility testing
- User testing with individuals with disabilities
We welcome your feedback on the accessibility of this website.

This website relies on the following technologies to work with your browser and assistive technology:
- HTML5 semantic markup
- CSS3 with accessibility enhancements
- JavaScript (with graceful degradation)
- ARIA (Accessible Rich Internet Applications) attributes
- Progressive enhancement principles
While we strive for full accessibility, we acknowledge that some limitations may exist:
- Third-party embedded content (videos, social media) may have varying accessibility levels
- PDF documents are provided with HTML alternatives when possible
- Live events may require additional accommodations - contact us in advance
