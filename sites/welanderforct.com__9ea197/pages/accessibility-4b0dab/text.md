Camera Camera Camera ACCESSIBILITY Mary is committed to including everybody in her campaign.
To this end, we try to make all campaign materials, such as this website, accessible to all.
Everyone should be able to participate in our democracy, regardless of ability.
Updating this website to be as accessible as possible is an ongoing process.
So far, the following measures have been taken: We have undergone a thorough self-evaluation of our compliance with accessibility standards.
The goal is to meet or exceed Web Content Accessibility Guidelines (WCAG) 2.1 AA.
Alternative text has been added to photos on this website.
If you come across an image that does not have alternative text, please let us know.
Previously, the light blue backgrounds on this website had white text, which was not compliant with accessibility standards.
All text should now have contrast ratios up to standard.
If you come across text that is hard to read, please let us know.
M ost text now have heading tags that have been manually assigned to ensure screen-reader software can correctly navigate the site.
We have ensured that all hyperlinks are underlined (with the exception of buttons), and attempted to differentiate website features without using color alone.
If you come across hyperlinks that are not underlined or a website feature that is differentiated with just color, please let us know.
We have installed an accessibility widget on the site to allow visitors to control visual elements to allow for easier navigation. ​ Prior to this undertaking, we already had accessibility features like video subtitles and transcripts.
If you are having difficulty navigating or using this website, have any concerns, questions, or suggestions, please do not hesitate to contact us at mary@welanderforct.com .
