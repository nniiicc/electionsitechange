동의 관리
웹 사이트가 제대로 작동하려면 필요한 쿠키가 절대적으로 필요합니다. 이러한 쿠키는 익명으로 웹 사이트의 기본 기능 및 보안 기능을 보장합니다.
기능 쿠키는 소셜 미디어 플랫폼에서 웹 사이트의 콘텐츠를 공유하고, 피드백을 수집하고, 기타 타사 기능을 공유하는 것과 같은 특정 기능을 수행하는 데 도움이 됩니다.
성능 쿠키는 방문자에게 더 나은 사용자 환경을 제공하는 데 도움이 되는 웹 사이트의 주요 성능 인덱스를 이해하고 분석하는 데 사용됩니다.
분석 쿠키는 방문자가 웹 사이트와 상호 작용하는 방식을 이해하는 데 사용됩니다. 이러한 쿠키는 방문자 수, 이탈률, 교통 소스 등의 지표에 대한 정보를 제공하는 데 도움이 됩니다.
광고 쿠키는 방문자에게 관련 광고 및 마케팅 캠페인을 제공하는 데 사용됩니다. 이 쿠키는 웹 사이트 전체의 방문자를 추적하고 정보를 수집하여 맞춤형 광고를 제공합니다.
다른 분류되지 않은 쿠키는 분석 중이며 아직 범주로 분류되지 않은 쿠키입니다.
